{% comment %} Semester status banner (#2157, #1177), rendered on every tenant page via base.html, staff only. Nudges the two states the semester workflow can silently sit in: - no semester open at all, so students can't join a course; - an open semester whose last day has passed, so it's probably time to archive it (archiving records final marks and frees that semester's students' deck seats). A deck can run more than one semester at once (#1781), so the second nudge is per semester: each one that has ended gets its own line, naming it and linking to its own archive page, and a semester still running is left alone. Each of those lines carries the semester's id in its own id attribute, since several can render at once. `config` comes from the config context processor; it is None on the public schema, which hides the banner entirely. Suppressed on a suspended deck (current_deck from the deck_status context processor): students can't sign in there anyway, so semester nudges are noise next to the suspension banner. {% endcomment %} {% if config and request.user.is_staff and not current_deck.is_suspended %} {% if config.has_no_open_semester %}
No semester is open: students can't join a course until you create and activate a new semester. Manage semesters.
{% else %} {% for semester in config.open_semesters %} {% if semester.has_ended %}
Semester {{ semester }} ended on {{ semester.last_day }}. Archive it to record final marks and free up your students' seats.
{% endif %} {% endfor %} {% endif %} {% endif %}
