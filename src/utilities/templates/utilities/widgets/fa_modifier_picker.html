{% comment %} Font Awesome modifier picker (utilities.fa_icon_widget.FontAwesomeModifierPickerWidget). Toggle buttons for the common transforms (rotate, flip, spin, pulse) write the space-separated "fa-" classes into the field below, which is hidden (its raw class string means nothing to a user): the buttons are the whole UI, and the hidden field carries the value the form submits. Behaviour lives in static/js/fa_modifier_picker.js; the classes flow into the icon field's live preview through the field's own input event. Rotate and Animate are "toggle-radio" (click the active button again to clear it), so there is no separate "none" button. {% endcomment %}
