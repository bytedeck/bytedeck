# Quick start

This quick start takes a new deck owner from nothing to students handing in work, in five steps. Set aside about half an hour.

1. **[Get your deck](get-your-deck.md):** request a deck, confirm your email, and sign in for the first time.
2. **[Set up your deck](set-up-your-deck.md):** name your deck and choose the access code your students sign up with.
3. **[Invite your students](invite-students.md):** students sign up with the access code and join a course.
4. **[Your first quests](first-quests.md):** see the starter quests every deck comes with, then write one of your own.
5. **[Review submissions](review-submissions.md):** approve your students' work, or return it with feedback.

!!! tip "Try it as a student first"
    Want to see what your students will see before you begin? Join the demo deck at [learn.bytedeck.com](https://learn.bytedeck.com) as a student.

## What a new deck comes with

You don't start from an empty deck. Every new deck has:

* a first quest, **Welcome to ByteDeck!**, which opens an **Orientation** campaign of short quests that teach students how to use ByteDeck;
* the **ByteDeck Proficiency** badge, which students earn by completing the Orientation campaign;
* a set of example badges (awards like Penny, Nickel and Dime, and teams) and **ranks** from "Digital Noob" up to "Master Digital Crafter";
* one **semester**, one **group** and one **course**, so students can join a course as soon as they sign up.

You can edit or replace any of it as you go: the quick start shows you where.
